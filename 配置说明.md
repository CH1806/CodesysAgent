1、环境准备：python3.12，uv命令行工具
2、创建并虚拟环境
      python -m venv .venv
      .venv\Scripts\activate
3、安装项目依赖    
      uv pip install -e .
      uv pip install uvicorn fastapi
4、配置mcp服务器和大模型apikey
      在根目录创建.fast-agent文件夹，在此文件夹内创建fast-agent.yaml文件，在文件夹中粘贴以下内容，模型名称和apikey，baseurl进行替换，codesys服务器中的路径信息替换。
            default_model: openai.gemini-3-flash-preview
            openai:
              api_key: "sk-xxxxxxxxxxxxxxxxxxxxxxxx"
              base_url: "https://tokenbaby.org/v1"
            
            # =====================================================================
            # 2. 对话历史压缩配置（防止长对话超出大模型上下文限制）
            # =====================================================================
            compaction:
              auto: true
              threshold: 0.85
              keep_turns: 2
            
            # =====================================================================
            # 3. 本地 CODESYS MCP 服务器连接配置
            # =====================================================================
            mcp:
              defaults:
                protocol_mode: auto
                reconnect_on_disconnect: true
                include_instructions: true
            
              client:
                auto_sampling: true
            
              diagnostics:
                enabled: true
                timeline:
                  steps: 20
                  step_seconds: 15
            
              servers:
                codesys:
                  command: "D:\\codesys-mcp-new\\mcptoolkit-for-codesys-main\\mcptoolkit-for-codesys-main\\.venv\\Scripts\\mcptoolkit-for-codesys.exe"
                  args:
                    - "--sp"
                    - "22"
                  env:
                    MCPTOOLKIT_WORKDIR: "D:\\codesys-mcp-new\\workdir"
                  cwd: "D:\\codesys-mcp-new\\mcptoolkit-for-codesys-main\\mcptoolkit-for-codesys-main\\.venv\\Scripts"
5、运行 python app.py,运行成功之后打开前端http://127.0.0.1:8000
